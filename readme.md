# 婚礼邀请函
手机风格的婚礼邀请函, 前后端全套功能完善.

- 已抽离配置, 可以通过简单的修改即可成为其他人的邀请函.
- 已经过多人实际使用, 评价很好.
- 支持男女版.
- 支持祝福管理.

前端使用 `vue`, 后端使用 `express/mongoose`

- 示例: 演示模式, 图片随机生成, 祝福为示例祝福
- 实例: 黄友应的婚礼邀请函

## 页面
- 来电页: 响铃, 接听后进入通话页
- 接听页: 根据男女版播放语音邀约, 点击挂断后进入桌面页
- 桌面页: 有各个图标, 点击后进入各个页面
- 邀请页: 根据男女版显示邀请文字及倒计时
- 通讯页: 可以点击新娘新郎的号码拨打电话
- 微信页: 点击听新娘新郎的另一条语音消息
- 集成页: 有交互式的拍照效果, 然后引导进入邀请页,相册页,祝福页
- 祝福页: 闪烁祝福按钮引导祝福, 以弹幕方式显示祝福
- 相册页: 多张照片组合列表
- 地图页: 可以进行导航功能
- 调试页: 输入密码后, 删除某条祝福, 或进行页面调试

## 配置
每个页面的上的内容都有很大的可配置性.

### 前端配置
参考 `src/cfg.js` 文件.


### 后端配置
后端代码位于 `server` 目录中, 配置参考 `server/cfg.js` 文件.
